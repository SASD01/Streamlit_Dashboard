# Portal Logistic Services and Solutions S.A.S

Aplicación web para consultar información operativa con acceso personalizado mediante Microsoft.

### Módulos

Alertas · Llamadas · Preoperacionales · Combustibles · Reembolsos · Administración

> Los módulos están en desarrollo.

### Iniciar

```bash
uv run streamlit run src/streamlit01/app.py
```

Configura la conexión a la base de datos y Microsoft Entra ID en `.env`.
